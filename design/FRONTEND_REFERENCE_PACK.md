# MEMORA — FRONTEND REFERENCE PACK

This file defines the visual references and design principles for the Memora frontend.

This is a **reference document**, not a collection of templates to copy.

Each reference has a specific purpose. Combine the principles into an original Memora visual identity.

---

# 01 — CORE VISUAL DIRECTION

## Memora should feel like:

> A private digital memory archive from an alternate version of the early 2000s, redesigned using modern iOS interaction principles.

The visual identity combines:

- Dark UI
- Translucent materials
- Y2K technology
- Gothic atmosphere
- Modern iOS interaction
- Premium minimalism
- Tactile surfaces
- Subtle futuristic details

The interface should feel:

- mysterious
- personal
- quiet
- tactile
- nostalgic
- premium
- slightly futuristic

The interface should feel like an **object**, rather than a generic website.

---

# 02 — WHAT MEMORA MUST NOT LOOK LIKE

Do NOT make Memora look like:

- Generic SaaS
- Generic AI dashboard
- Crypto dashboard
- Cyberpunk UI
- Gaming UI
- RGB/neon UI
- Generic glassmorphism
- An Apple clone
- A literal early-2000s website
- A Halloween website
- A gothic merchandise website
- A dashboard made entirely from floating cards

Avoid visual trends simply because they are popular.

The design should feel intentional and original.

# 05 — APPLE MATERIALS

Official reference:

https://developer.apple.com/design/human-interface-guidelines/materials

Use this as the primary reference for translucent surfaces.

## Borrow:

- Layered surfaces
- Blur
- Transparency
- Depth
- Material hierarchy
- Foreground/background separation
- Content readability over translucent surfaces

## Important rule

Glass is a **hierarchy mechanism**, not decoration.

Do NOT apply the same glass effect to every element.

Memora should have several levels of material.

### Material 01 — Background

Almost opaque dark background.

Used for:

- application background
- main content

### Material 02 — Navigation

Slightly translucent dark surface.

Used for:

- sidebar
- bottom navigation
- persistent controls

### Material 03 — Floating

More translucent surface.

Used for:

- floating cards
- search
- contextual controls

### Material 04 — Modal

Strong translucent surface.

Used for:

- dialogs
- sheets
- focused workflows

### Material 05 — Overlay

Highest visual separation.

Used for:

- important confirmation
- destructive actions
- high-focus workflows

# 18 — MEMORY CARDS

Memora's memory cards are the most important content component.

A memory should feel like a **fragment from a personal archive**.

Each memory can contain:

- title/content
- timestamp
- source
- tags
- metadata
- importance/relevance
- optional media

The card should prioritize the actual memory.

Do NOT make every memory look like:

```text
┌─────────────┐
│     72%     │
│ STATISTIC   │
└─────────────┘
```

This is not a productivity dashboard.

The memory itself is the hero.

# 19 — SEARCH

Search should feel like entering the user's memory archive.

The search interface should be one of the strongest interactions in Memora.

Use:

- floating search field
- keyboard-first interaction
- translucent command panel
- instant results
- subtle highlighting
- contextual filters
- smooth expansion
- quick actions

Possible atmosphere:

```text
MEMORA

21:42
```

Avoid turning it into a generic AI command palette.

---

# 20 — MODALS AND SHEETS

Prefer:

- sheets
- floating panels
- contextual surfaces

over traditional browser-looking dialogs.

When a modal opens:

1. Background becomes slightly darker.
2. Existing content remains visible.
3. Modal receives stronger material separation.
4. Blur/depth increases.
5. Modal enters with a short spatial animation.

The animation should communicate:

> "This surface moved into focus."

Not:

> "A PowerPoint transition just happened."

---

# 21 — MOTION

Reference:

https://developer.apple.com/design/human-interface-guidelines/motion

Use:

- 150–250ms normal transitions
- slightly slower sheet transitions
- subtle spring-like easing
- opacity + transform
- scale used sparingly
- spatial continuity

Avoid:

- bouncing everything
- spinning
- excessive zoom
- constant movement
- animation on every hover

Motion should make the UI feel tactile.

# 25 — DESIGN WEIGHTING

These are rough design priorities, not literal percentages that must be encoded.

```text
iOS / Apple interaction
████████████████████ 30%

Dark translucent material
███████████████      25%

Y2K hardware
████████████         20%

Gothic atmosphere
████████             15%

Dark editorial
█████                10%
```

The key idea:

**iOS controls usability.**

**Dark/translucent materials control the environment.**

**Y2K controls nostalgia.**

**Gothic controls atmosphere.**

**Editorial design controls typography and negative space.**

None of the aesthetics should overpower the others.

# 29 — FINAL RULE

When deciding whether to add a visual effect, ask:

> Does this make Memora feel more like a personal digital archive?

If yes, consider it.

If it only makes the UI look more impressive in a screenshot, do not add it.

The product is the memory.

The visual design exists to make the memory feel valuable.
