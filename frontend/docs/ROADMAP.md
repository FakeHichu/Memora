# Roadmap

The following features are intentionally deferred until the core MVP reaches a stable state.

- Friend groups
- Photo roulette
- Weekly awards
- Anonymous mystery photos
- Memory map
- Song attachments
- Then-vs-now
- Automatic video generation
- Future Us time capsules
- AI highlights

## MVP path

1. Authentication and protected routes
2. Database and RLS
3. Class creation and membership management
4. Private photo storage and signed URLs
5. Daily photo flow and one-photo-per-day enforcement
6. Feed, reactions, and moderation
7. Notifications and calendar memory browsing
8. Yearbook foundation and polish
